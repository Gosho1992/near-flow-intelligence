# Sources

This register identifies the primary inputs and their provenance. Derived values (daily flows, rolling windows, basket equivalents, rates and chart series) are calculated by the project using the definitions in [METHOD.md](METHOD.md); they are not copied verbatim from a source page. Raw NEAR and FastNEAR responses are cached (gzipped) in `data/raw/`, keyed by request hash.

## Derived-unit definitions

- **Signed NRR net custody flow:** `creations - redemptions` per daily window. Staking rewards are excluded.
- **Average per day:** sum of signed daily net custody flow divided by the number of complete daily windows in the specified period.
- **Basket equivalent:** daily NEAR amount divided by `10,000 × NEAR_per_share` from the latest included Bitwise snapshot. The prospectus defines the 10,000-share creation unit; the conversion does not prove market trading.
- **Issuance:** measured gross NEAR minted over the window, derived from total-supply changes at epoch boundaries.
- **Buyback-fund balance change:** daily change in native NEAR plus wNEAR at the defined accounts. This is not an executed-purchase series.
- **USD-equivalent chart mode:** cumulative NEAR line values multiplied by the latest archived `NAV / NEAR_per_share` price. It is a dated valuation conversion, not a live market-price series.

For formulas and date-window boundaries, see METHOD.md and the documented build code in `nfi/build.py`.
